1. 先安装原 Mod：`Informative WANTED Posters`。
2. 将本项目中的 `Informative WANTED Posters CN.mod` 放入 Kenshi 的 `mods` 目录。
3. 在 Mod 加载顺序中，将本翻译 Mod 放在原 Mod **下方**，使翻译记录覆盖原 Mod 的英文文本。
